# دفتر تصمیم‌های نسخه اول

## وضعیت‌ها

- `APPROVED`: از PRD یا طراحی تثبیت‌شده استخراج شده و مبنای اجرا است.
- `PROPOSED`: پیشنهاد پایه برای پیاده‌سازی است و مالک مربوط باید تأیید کند.
- `OPEN`: بدون تصمیم؛ مانع اجرای بخش وابسته است.
- `DEFERRED`: برای نسخه بعدی کنار گذاشته شده است.

## روش تصویب

برای تغییر وضعیت یک تصمیم به `APPROVED` باید نام تأییدکننده، تاریخ، متن نهایی تصمیم و در صورت نیاز مرجع حقوقی یا مالی در همین فایل ثبت شود. تصمیم شفاهی یا رفتار فعلی کد جایگزین تصویب نیست.
