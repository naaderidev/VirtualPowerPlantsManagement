# JavaScript Rules

- Prefer `const`.
- Use strict equality.
- Avoid implicit coercion when it obscures intent.
- Use optional chaining and nullish coalescing when they improve clarity.
- Use destructuring/spread only when readability improves.
- Avoid clever metaprogramming unless required.
- Avoid `any` in TypeScript when a real type can be expressed.
- Prefer explicit data transformations.
- Preserve invariants instead of allowing invalid states to spread.
