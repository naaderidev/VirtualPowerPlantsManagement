# SOLID Rules

Treat SOLID as a diagnostic toolkit, not a checklist.

- SRP: separate responsibilities when they create independent reasons to change.
- OCP: use stable extension points when variation is real.
- LSP: subtypes MUST preserve the contract expected by consumers.
- ISP: keep interfaces focused and client-oriented.
- DIP: depend on stable abstractions when that actually reduces coupling.

Do not introduce interfaces, factories, or dependency injection solely to satisfy SOLID mechanically.
