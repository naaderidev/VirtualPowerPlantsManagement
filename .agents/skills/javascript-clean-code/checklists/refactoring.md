# Refactoring Checklist

- [ ] Existing behavior is understood.
- [ ] Refactor has a concrete purpose.
- [ ] Public behavior is preserved unless intentionally changed.
- [ ] Tests protect important behavior.
- [ ] Responsibilities become clearer.
- [ ] Dependencies become simpler.
- [ ] Duplication is reduced without creating premature abstraction.
- [ ] Complexity is reduced or intentionally justified.
